# firmware-engineering-journey

## Purpose
This repository documents my hands-on journey toward Firmware Engineering. It contains experiments, exercises, notes, debugging investigations, and projects developed while learning embedded C/C++, microcontroller programming, RTOS, hardware communication protocols, firmware testing, and automation.

## Hardware
- Raspberry Pi Pico 2 W (RP2350)
- ESP32-WROOM-32

## Learning Objectives
- Strengthen C/C++ fundamentals for embedded systems
- Understand microcontroller architecture and memory
- Learn GPIO, interrupts, timers, UART, I²C and SPI
- Understand RTOS fundamentals
- Develop firmware debugging skills
- Build automated firmware tests with Python
- Explore USB and storage-related protocols
